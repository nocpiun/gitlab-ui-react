GitLab UI React 将 GitLab [Pajamas 设计系统](https://design.gitlab.com)背后的组件库从 Vue 移植到 React。项目旨在保持上游 GitLab UI 组件的外观、行为、交互模式与无障碍特性，同时提供符合 React 习惯的类型安全 API。

> [!warning]
> 🚧 **本项目仍在密集开发中。** 🚧
>
> 大部分代码和测试由 AI（Codex 和 Kimi Code）编写。人类负责架构、优先级和设计决策，但尚未逐行审查大部分代码。使用时请自行评估风险。

## 已有内容

- 可分发的 GitLab 设计令牌包位于 `packages/tokens`。完整的令牌参考请查看官方[设计令牌目录](https://design.gitlab.com/product-foundations/design-tokens-directory)。
- 基础样式位于 `packages/styles/src`，预构建样式表位于 `packages/styles/dist/gitlab-ui.css`。
- 基础组件，包括 `GlButton`、`GlLink`、`GlBadge` 和 `GlCard`。
- 表单组件，包括 `GlFormInput`、`GlFormTextarea`、`GlFormCheckbox`、`GlFormRadio` 和 `GlFormSelect` 等。
