## 用法

```tsx
import {
  GlAlert,
  GlAlertActions,
  GlAlertDescription,
} from "gitlab-ui-react/alert";
import { GlButton } from "gitlab-ui-react/button";
```

```tsx
<GlAlert dismissible={false}>
  <GlAlertDescription>Your preferences were updated.</GlAlertDescription>
  <GlAlertActions>
    <GlButton>Review changes</GlButton>
  </GlAlertActions>
</GlAlert>
```

## 默认

当当前情境中出现动态系统状态时使用警报。如果消息必须保留到其对应的状态得到解决，请先使用不可关闭的警报。

## 可关闭的警报

只有消息可以安全移除时才允许用户关闭。`GlAlert` 不会自行隐藏，因此父组件必须在 `onDismiss` 触发时更新状态并移除警报。

## 变体

应根据消息含义选择变体，而不是只考虑视觉强调程度。严重问题使用 danger，潜在风险使用 warning，在其他位置完成的操作结果使用 success，动态状态使用 info，有用的产品指导使用 tip。

## 标题与操作

当标题有助于用户识别触发警报的事件时，可以添加一个简短标题。在 `GlAlertActions` 中最多放置两个明确的恢复或继续操作；主要操作使用 confirm 变体，次要操作使用 default 变体。

## 无障碍

- 警报用于动态通知，不应用来展示永久可见的说明或上下文帮助。
- danger、warning 和 success 变体使用 `role="alert"`；info 和 tip 变体使用 `role="status"`。默认的 `aria-live="polite"` 不会打断屏幕阅读器当前的朗读。
- 仅对关键且有时效性的消息设置 `politeness="assertive"`。对于需要用户操作的消息，应将其放在相关内容附近，并在合适时通过 ref 把焦点移动到警报上。
- 选择 `headerLevel`，使标题符合页面的逻辑标题层级。
- 提供本地化的 `dismissLabel`、处理 `onDismiss`，并且只在消息可以安全移除时提供关闭功能。
- 更新后需要辅助技术朗读整条消息时，设置 `aria-atomic="true"`。

## API

下面列出组件专有的属性。`GlAlert`、`GlAlertDescription` 和 `GlAlertActions` 还会转发受支持的 `div` 属性与 ref。

### `GlAlert`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `variant` | 将语义样式设置为 `danger`、`warning`、`success`、`info` 或 `tip`。 | `"info"` |
| `title` | 在警报内容之前添加简短标题。 | — |
| `headerLevel` | 将标题层级设置为 `1` 到 `6`。 | `2` |
| `dismissible` | 显示关闭按钮；可见性仍由父组件控制。 | `true` |
| `dismissLabel` | 设置关闭按钮的无障碍标签。 | `"Dismiss"` |
| `onDismiss` | 关闭按钮被激活时调用。 | — |
| `politeness` | 将 `aria-live` 设置为 `polite`、`assertive` 或 `off`。 | `"polite"` |
| `sticky` | 将警报固定在滚动容器顶部；同一时间只应使用一个固定警报。 | `false` |
| `children` | 警报内容，通常由描述和操作辅助组件组合而成。 | — |

### `GlAlertDescription`

提供标准的消息布局，并接受 `children` 与受支持的 `div` 属性。

### `GlAlertActions`

排列自定义操作控件，并接受 `children` 与受支持的 `div` 属性。
