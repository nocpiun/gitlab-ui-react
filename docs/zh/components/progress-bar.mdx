## 用法

```tsx
import { GlProgressBar } from "gitlab-ui-react/progress-bar";
```

```tsx
<GlProgressBar aria-label="Upload progress" value={64} />
```

## 无障碍

- 为每个 Progress bar 提供具体的 `aria-label`，尤其是页面同时出现多个进度指示器时。
- 保持 `value` 在 `0` 和 `max` 之间，并随操作进度更新。
- 不要只依赖颜色表达成功、警告或失败。
- 当用户需要准确百分比或当前状态时，在附近添加可见文字。

## API

`GlProgressBar` 会将受支持的属性传递给外层 `<div>`。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `value` | 设置当前进度值。 | `0` |
| `max` | 设置最大值；非正数会回退到 `100`。 | `100` |
| `variant` | 设置 `primary`、`success`、`warning` 或 `danger`。 | `"primary"` |
| `height` | 设置 `8px` 或 `1rem` 等自定义 CSS 高度。 | `"1rem"` |
| `aria-label` | 设置进度指示器的无障碍名称。 | `"Progress bar"` |
