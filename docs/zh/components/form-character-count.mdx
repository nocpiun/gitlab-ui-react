---

## 用法

```tsx
import { GlFormCharacterCount } from "gitlab-ui-react/form-character-count";
```

```tsx
<GlFormCharacterCount
  countTextId="summary-count"
  limit={100}
  overLimitText="1 character over limit."
  remainingCountText="25 characters remaining."
  value="Lorem ipsum" />
```

## 默认

当文本字段具有明确长度限制时使用字符计数。可见计数会立即更新，而礼貌型 live region 会延迟更新，避免过于频繁地播报。

## 无障碍

- 通过 `aria-describedby` 将输入控件关联到 `countTextId`。
- 为 `remainingCountText` 和 `overLimitText` 提供本地化内容，并在两者中包含当前计数。
- 如果超出限制会阻止提交，不要仅将计数器作为验证反馈。

## API

`GlFormCharacterCount` 会将受支持的属性传递给根 `<div>`，且不接受未命名的 children。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `countTextId` | 设置由输入控件引用的礼貌型 live region ID。 | — |
| `limit` | 设置字符限制。 | — |
| `value` | 提供当前输入值。 | `""` |
| `remainingCountText` | 提供未超出限制时显示的本地化文字。 | — |
| `overLimitText` | 提供超出限制时显示的本地化文字。 | — |
