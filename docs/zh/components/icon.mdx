## 用法

```tsx
import { GlIcon } from "gitlab-ui-react/icon";
```

```tsx
<GlIcon name="information-o" />
```

## 默认

Icon 默认为装饰性内容，并继承当前文字颜色。当图标本身可能产生歧义时，应与可见文字搭配使用。

## 无障碍

- 装饰性图标会自动对辅助技术隐藏。
- 独立的信息图标应通过 `ariaLabel` 或原生 `aria-label` 提供其所传达含义的无障碍名称。
- 不要让 `GlIcon` 本身可点击。将交互图标放入具有无障碍名称的语义化按钮或链接中。
- 同一概念或操作应始终使用同一图标。

## API

`GlIcon` 还会将受支持的 SVG 属性传递给渲染后的 `<svg>` 元素。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `name` | 选择 `@gitlab/svgs` 中内置的图标。 | — |
| `size` | 将图标尺寸设为 `8`、`12`、`14`、`16`、`24`、`32`、`48` 或 `72` 像素。 | `16` |
| `variant` | 设置 `current`、`default`、`subtle`、`strong`、`disabled`、`link`、`info`、`warning`、`danger` 或 `success` 颜色。 | `"current"` |
| `ariaLabel` | 为非装饰性图标提供无障碍名称。 | — |
