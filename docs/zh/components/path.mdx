## 用法

```tsx
import {
  GlPath,
  GlPathItem,
  GlPathItemMetric,
  GlPathItemTitle,
} from "gitlab-ui-react/path";
```

```tsx
<GlPath>
  <GlPathItem value="plan">
    <GlPathItemTitle>Plan</GlPathItemTitle>
    <GlPathItemMetric>2 days</GlPathItemMetric>
  </GlPathItem>
</GlPath>
```

## 默认

Path 适合展示少量有序阶段。每个 Item 需要唯一的 `value` 和一个 Title；可选的 Metric 可以表示时间、持续时间或其他紧凑数值。

## 无障碍

- 阶段标题应简短，并保持符合逻辑的顺序。
- 选中阶段会使用 `aria-current` 标记；受控模式通过 `onValueChange` 更新状态。
- 如果内容不是可选择的工作流状态，请勿将 Path 当作通用 Breadcrumb 或 Stepper。
- Path 可能溢出时，应本地化 `scrollLeftLabel` 和 `scrollRightLabel`。

## API

### `GlPath`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `defaultValue` | 设置非受控模式下的初始选中值。 | 第一个 Item |
| `value` | 控制选中的 Item 值。 | — |
| `onValueChange` | 返回选择请求。 | — |
| `backgroundColor` | 设置溢出渐隐区域下方的颜色。 | `"rgba(0,0,0,0)"` |
| `scrollLeftLabel` | 命名向左滚动控件。 | `"Scroll left"` |
| `scrollRightLabel` | 命名向右滚动控件。 | `"Scroll right"` |

### `GlPathItem`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `value` | 提供稳定且唯一的选择值。 | 必填 |
| `icon` | 在 Title 前添加装饰性 GitLab Icon。 | — |
| `disabled` | 阻止 Item 被选择。 | `false` |
| `children` | 需要一个 `GlPathItemTitle`，可包含一个 `GlPathItemMetric`。 | 必填 |

### `GlPathItemTitle`

接受 `children` 和受支持的 `span` 属性。

### `GlPathItemMetric`

接受 `children` 和受支持的 `span` 属性。
