## 用法

```tsx
import { GlSkeletonLoader } from "gitlab-ui-react/skeleton-loader";
```

```tsx
<GlSkeletonLoader />
```

## 无障碍

- 在 Skeleton 外保留可见的页面或区块标题，让用户知道正在加载什么。
- 不要在加载 Skeleton 中放置可交互控件。
- 内置 SVG Title 会提示正在加载；用户偏好减少动态效果时，动画会自动移除。
- 真实内容可用后应立即替换 Skeleton。

## API

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `lines` | 设置自动生成的文字行数。 | `3` |
| `equalWidthLines` | 让所有自动生成的行占满宽度。 | `false` |
| `width` | 设置 SVG viewBox 宽度和默认 Wrapper 宽度。 | 自动 |
| `height` | 设置 SVG viewBox 高度和默认 Wrapper 高度。 | 自动 |
| `children` | 使用自定义 SVG Shape 替代自动生成的行。 | — |
| `preserveAspectRatio` | 设置 SVG `preserveAspectRatio`。 | `"xMidYMid meet"` |
| `uniqueKey` | 设置内部 SVG ID 的稳定前缀。 | 自动生成 |
| `baseUrl` | 页面使用 Base URL 时，为 SVG Fragment 引用添加前缀。 | `""` |
