---
title: Form radio
description: 让用户从一组相关选项中选择且仅选择一个值。
---

## 用法

```tsx
import { GlFormRadio } from "gitlab-ui-react/form-radio";
import { GlFormRadioGroup } from "gitlab-ui-react/form-radio-group";
```

```tsx
<GlFormRadioGroup
  aria-label="Visibility"
  defaultValue="private"
  name="visibility">
  <GlFormRadio value="private">Private</GlFormRadio>
  <GlFormRadio value="public">Public</GlFormRadio>
</GlFormRadioGroup>
```

## 默认

当一组相关选项中只能选择一个值时，使用 `GlFormRadioGroup`。Group 会与子 Radio 共享值、名称、验证状态、必填状态和禁用状态。

## 无障碍

- 使用带简洁 `GlFormFieldLegend` 的 `GlFormFieldSet` 包裹相关选项。
- 通过 `aria-label` 为 `GlFormRadioGroup` 提供独立的无障碍名称，并保留每个选项的可见标签。
- 保持选项集中并垂直排列，不要在 Group 中插入无关的交互内容。
- 适当情况下预选常用或推荐选项，但不要仅为避免空状态而预选。
- 当用户可以选择零个或多个选项时，改用 Checkbox。

## API

两个组件都会传递受支持的原生属性。Group 中的 Radio 会从 Group 获取选择与共享表单状态。

### `GlFormRadio`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `checked` | 在 Group 外控制选中状态。 | — |
| `defaultChecked` | 设置非受控模式下的初始选中状态。 | `false` |
| `onCheckedChange` | 报告下一个选中状态。 | — |
| `value` | 设置原生值及 Group 中的选项值。 | `true` |
| `disabled` | 禁用 Radio。 | `false` |
| `required` | 将具有名称的 Radio 标记为必填。 | `false` |
| `state` | 设置有效、无效或中性外观。 | `null` |
| `help` | 在标签下方渲染帮助内容。 | — |

### `GlFormRadioGroup`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `value` | 控制选中的选项值。 | — |
| `defaultValue` | 设置非受控模式下的初始选择。 | `null` |
| `onValueChange` | 报告选中的选项值。 | — |
| `options` | 从字符串、数字或选项对象生成 Radio。 | `[]` |
| `name` | 设置子 Radio 的共享名称。 | 生成的 Group ID |
| `disabled` | 禁用 Group 中的所有 Radio。 | `false` |
| `required` | 将 Group 中的 Radio 标记为必填。 | `false` |
| `state` | 设置 Group 与子项的验证外观。 | `null` |
