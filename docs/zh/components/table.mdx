## 用法

```tsx
import {
  GlTable,
  GlTableBody,
  GlTableCaption,
  GlTableCell,
  GlTableFooter,
  GlTableHead,
  GlTableHeader,
  GlTableRow,
} from "gitlab-ui-react/table";
```

```tsx
<GlTable>
  <GlTableCaption>Project members</GlTableCaption>
  <GlTableHeader>
    <GlTableRow>
      <GlTableHead>Name</GlTableHead>
    </GlTableRow>
  </GlTableHeader>
  <GlTableBody>
    <GlTableRow>
      <GlTableCell>Norcleeh</GlTableCell>
    </GlTableRow>
  </GlTableBody>
  <GlTableFooter>
    <GlTableRow>
      <GlTableCell>1 member</GlTableCell>
    </GlTableRow>
  </GlTableFooter>
</GlTable>
```

## 无障碍

- 使用 `GlTableCaption` 描述 Table。即使 Caption 只对屏幕阅读器可见，也比省略更好。
- 列 Header 使用带 `scope="col"` 的 `GlTableHead`，行 Header 使用 `scope="row"`。
- 只有真正的表格数据才使用 Table；无关条目的集合应使用列表。
- 父组件实现排序时，应通过 `aria-sort` 暴露状态，并在 Header 中使用键盘可操作的控件。

## API

### `GlTable`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `bordered` | 为每个 Cell 添加边框。 | `false` |
| `borderless` | 移除 Table 边框，并在视觉上优先于 `bordered`。 | `false` |
| `captionTop` | 将 Caption 放在 Table 上方。 | `false` |
| `fixed` | 使用固定 Table 布局。 | `false` |
| `hover` | Hover 时高亮 Body Row。 | `false` |
| `noBorderCollapse` | 分隔 Cell 边框，而不是折叠边框。 | `false` |
| `outlined` | 添加外边框。 | `false` |
| `small` | 使用紧凑的 Cell Padding。 | `false` |
| `stacked` | 在所有宽度或 `sm`、`md`、`lg`、`xl` 以下堆叠 Row。 | `false` |
| `stickyHeader` | 固定 Header；字符串值还会设置 Wrapper 的最大高度。 | `false` |
| `striped` | 为 Row 添加交替背景。 | `false` |

### `GlTableCaption`

接受 `children` 和受支持的 `caption` 属性。

### `GlTableHeader`

接受 `children` 和受支持的 `thead` 属性。

### `GlTableBody`

接受 `children` 和受支持的 `tbody` 属性。

### `GlTableFooter`

接受 `children` 和受支持的 `tfoot` 属性。

### `GlTableRow`

接受 `children` 和受支持的 `tr` 属性。

### `GlTableHead`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `scope` | 定义 `GlTableHead` 标注 Row 还是 Column。 | `"col"` |
| `stackedHeading` | 提供堆叠模式下显示的 Header Cell Label。 | — |

### `GlTableCell`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `stackedHeading` | 提供堆叠模式下显示的 Data Cell Label。 | — |
