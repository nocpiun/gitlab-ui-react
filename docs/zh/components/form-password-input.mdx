## 用法

```tsx
import { GlFormPasswordInput } from "gitlab-ui-react/form-password-input";
```

```tsx
<GlFormPasswordInput id="password" />
```

## 默认

对于用户可能需要在提交前核对的敏感值使用 Password Input。值默认隐藏，相邻按钮用于切换其可见性。

## 只读与禁用

当值需要保持可读、可显示、可复制和可提交时使用 `readOnly`。仅当整个控件都应不可用且不参与表单提交时使用 `disabled`。

## 无障碍

- 使用相同的 `htmlFor` 与 `id` 将输入关联到可见标签。
- 对 `revealLabel` 和 `hideLabel` 进行本地化；它们同时作为切换按钮的无障碍名称和 Tooltip。
- 对其他敏感值使用更具体的切换标签，例如 Access Token。
- 当键盘和屏幕阅读器用户仍需查看值时，优先使用 `readOnly` 而不是 `disabled`。

## API

`GlFormPasswordInput` 继承受支持的 `GlFormInput` 属性，但组件会自行控制 `type`。其 ref 指向底层输入元素。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `value` | 控制输入值。 | — |
| `defaultValue` | 设置非受控模式下的初始值。 | — |
| `initialVisibility` | 初始显示输入值。 | `false` |
| `onVisibilityChange` | 激活切换按钮后报告新的可见状态。 | — |
| `revealLabel` | 在值隐藏时为切换按钮提供标签。 | `"Reveal password"` |
| `hideLabel` | 在值显示时为切换按钮提供标签。 | `"Hide password"` |
| `disabled` | 禁用输入与可见性切换按钮。 | `false` |
| `inputClassName` | 为内部输入而非外层容器添加 class。 | — |
| `width` | 将外层容器限制为固定或响应式输入宽度。 | `null` |
