## 用法

```tsx
import {
  GlCard,
  GlCardContent,
} from "gitlab-ui-react/card";
```

```tsx
<GlCard>
  <GlCardContent>OPanel activity</GlCardContent>
</GlCard>
```

## 默认

Card 由可选页头、必需的主要内容和可选页脚组合而成。它适合承载从视觉分隔和可重复结构中获益的独立主题。

## 仅内容

当一个主题需要 Card 外观但没有独立页头或页脚时，只渲染 `GlCardContent`。如果只是进行简单的视觉分隔，并不存在有意义的内容分组，应优先使用普通 HTML 以及间距或边框工具类。

## 无障碍

- Card 是带视觉样式的 `div`，不是地标。仅当 Card 在页面中的角色确实需要时，才添加语义结构。
- 在 `GlCardHeader` 中放置层级恰当的标题，并确保标题层级与周围页面结构一致。
- 操作应使用语义化链接和按钮。当容器中还包含嵌套交互元素时，不要让整个容器表现为一个大型控件。
- 展示一组相关 Card 时，使用父级 `ul`，并将每个 Card 放入一个 `li`。
- 同一组可比较 Card 的内部结构应保持一致，以便快速浏览。

## API

`GlCard`、`GlCardHeader`、`GlCardContent` 和 `GlCardFooter` 没有组件专有属性。每个组件都会渲染 `div`、转发 ref，并接受受支持的 `div` 属性。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `children` | 提供 Card 或组合部件的内容。 | — |
| `className` | 在保留组件必需类名的同时添加类。 | — |
