## 用法

```tsx
import { GlLabel } from "gitlab-ui-react/label";
```

```tsx
<GlLabel
  backgroundColor="#D9C2EE"
  title="Documentation"
  target="#documentation" />
```

## 默认

## 无障碍

- 可见标题应能独立表达含义，不能仅依赖颜色区分类别。
- 设置 `target` 后，标题会成为 Link；用于导航时应提供真实目标地址。
- 启用 `showCloseButton` 时必须提供 `onClose`，并在按钮触发后从状态中移除 Label。
- 移除按钮会根据 `title` 生成无障碍名称；周围说明文字仍需按需本地化。

## API

`GlLabel` 还会将受支持的 `<span>` 属性传递给根元素。

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `backgroundColor` | 设置背景颜色，并自动选择有对比度的文字颜色。 | 必填 |
| `title` | 设置可见文字和 Link 名称。 | 必填 |
| `target` | 将标题变成指向该 URL 的 Link。 | `""` |
| `scoped` | 在最后一个 `::` 处分隔标题。 | `false` |
| `description` | 添加 Tooltip 描述。 | `""` |
| `footer` | 添加 Tooltip 的弱化页脚文字。 | `""` |
| `showCloseButton` | 显示移除按钮。 | `false` |
| `disabled` | 禁用移除按钮。 | `false` |
| `onClose` | 在移除按钮被触发时调用。 | — |
| `tooltipPlacement` | 将 Tooltip 放在 `top`、`right`、`bottom` 或 `left`。 | `"top"` |
