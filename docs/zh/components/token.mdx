## 用法

```tsx
import { GlToken } from "gitlab-ui-react/token";
import { GlTokenSelector } from "gitlab-ui-react/token-selector";
```

```tsx
<GlToken viewOnly>Documentation</GlToken>
```

## Token selector

使用 `GlTokenSelector` 从可搜索列表中选择多个值。候选项筛选由父组件通过 `onInputValueChange` 控制，已选项可通过 `value` 和 `onValueChange` 进行受控管理。

## 无障碍

- 每个 Token selector 都需要原生 `<label>` 通过 `htmlFor` 与 `id` 关联，或者提供 `aria-label` 或 `aria-labelledby`。
- Item 名称应唯一且含义清楚，不能只依赖 Token 颜色。
- 同时出现多个独立 Token 时，为移除按钮提供具体的 `removeLabel`。
- Selector 支持方向键导航、Enter 选择，以及通过 Backspace 或 Delete 移动到并移除 Token。

## API

### `GlToken`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `children` | 提供 Token 内容。 | — |
| `variant` | 设置 `default`、`search-type` 或 `search-value` 样式。 | `"default"` |
| `viewOnly` | 隐藏移除按钮。 | `false` |
| `removeLabel` | 设置移除按钮的无障碍名称。 | `"Remove"` |
| `onRemove` | 移除按钮被触发时调用。 | — |

### `GlTokenSelector`

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `items` | 提供具有唯一 String 或 Number ID 的可选项。 | `[]` |
| `defaultValue` | 设置初始非受控已选项。 | `[]` |
| `value` | 控制已选项。 | — |
| `onValueChange` | 返回完整的已选 Item 数组。 | — |
| `onInputValueChange` | 返回输入变化，让父组件筛选或请求 Item。 | — |
| `allowClearAll` | 显示清除全部已选项的按钮。 | `false` |
| `allowUserDefinedTokens` | 允许将非空输入添加为新 Token。 | `false` |
| `showAddNewAlways` | 仍有候选项时也显示用户自定义选项。 | `false` |
| `loading` | 在 Dropdown 中显示加载内容。 | `false` |
| `hideDropdownWithNoItems` | 没有可选项时隐藏 Dropdown。 | `false` |
| `state` | 设置有效（`true`）、无效（`false`）或中性（`null`）样式。 | `null` |
| `viewOnly` | 禁止编辑和移除 Token。 | `false` |
